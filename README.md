# rent-a-car-csharp
This is an application for the owner of a car rental company. I did it in C# Windows Forms App with ACCESS database

## Functionalities
### Home Panel
- Choosing Vehicle and Time Interval for rent
  
### Reservations Panel
- Remove Reservation
- Add Reservation
- Edit Reservation
- Show all Reservations and listing for choosen time interval
  
### Vehicles Panel
- Show all available Vehicles
- Add new Vehicle
  
### Categories Panel 
- Showing all available categories of Vehicles
- Add new Category

## Technologies
- C#
- .NET Framework
- VisualStudio
- ACCESS database
